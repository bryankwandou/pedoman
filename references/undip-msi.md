# Undip — Magister Sistem Informasi (Sekolah Pascasarjana): proposal tesis dan tesis

**Cakupan: hanya Program Studi Magister Sistem Informasi (PSMSI), Sekolah Pascasarjana
Undip.** Undip tidak punya pedoman penulisan tingkat Sekolah Pascasarjana yang bisa
ditemukan; tiap prodi menerbitkan sendiri. **Prodi Undip lain: minta pedoman prodinya**
— jangan pakai angka di file ini sebagai aturan Undip.

## 1. Format (MSI Bab II, hlm. 5–9)

| Butir | Ketentuan | Klausul |
|---|---|---|
| Kertas | "kwarto (A4)" **70 gram** | 2.2, hlm. 5 |
| Margin | kiri 4 · kanan 3 · **atas 4** · bawah 3 cm | 2.2 |
| Huruf | Times New Roman 12 | 2.2 · pengantar Bab II |
| Spasi | 1,5; abstrak spasi tunggal | 2.2, hlm. 6 |
| Paragraf | menjorok **8 karakter**, rata kiri-kanan; paragraf minimal dua kalimat | 2.2.2 (tercetak), hlm. 6 |
| Angka | angka dengan satuan ditulis angka kecuali di awal kalimat; desimal koma (62,3%); singkatan satuan tanpa titik | 2.3.1 |
| Nomor halaman | pendahuluan: Romawi kecil mulai halaman judul (tidak dicetak); utama: Arab; letak **kanan bawah**, awal bab **tengah bawah** | 2.3.3 |
| Bab | `BAB I` (Romawi kapital) dan judul di baris terpisah, simetris, kapital semua, tebal, tanpa titik | 2.3.4 |
| Subbab | `1.1.` — nomor Arab **diakhiri titik** | 2.3.4 |
| Persamaan | format *equation* (tidak boleh *cropping* dari jurnal), miring, menjorok 2 tab, nomor per bab `(2.1)` di tepi kanan; 2 kali jarak baris dari teks | 2.6, hlm. 8 |
| Gambar | judul **di bawah**, huruf 12, tanpa titik; 2 kali jarak baris dari teks; 1 spasi ke judul; nomor per bab; wajib sitasi sumber dan deskripsi | 2.7, hlm. 8–9 |
| Tabel | rata tengah; judul **di atas, rapat kiri**, huruf 12, tanpa titik; 1 spasi ke tabel; nomor per bab; wajib deskripsi | 2.8, hlm. 9 |

## 2. Sampul (MSI 2.1–2.2, hlm. 5)

- Judul **maksimal 16 kata**.
- Logo Undip **hitam-putih** (bukan berwarna), tinggi 5,5 cm × lebar 4,7 cm.
- Nama lengkap tidak disingkat, NIM di bawahnya; lalu Program Studi, Sekolah
  Pascasarjana, Universitas Diponegoro, Semarang, Tahun.
- Warna buffalo: draf proposal/tesis untuk ujian dan proposal sesudah ujian **Biru
  Dongker (Biru Undip)**; tesis **Hijau Toscha (Benhur)**.

## 3. Sitasi dan pustaka (MSI 2.4–2.5, hlm. 6–8)

| Butir | Ketentuan |
|---|---|
| Dalam teks | (nama, tahun); dua penulis dihubungkan "dan"; > 2 penulis **"dkk."** |
| et al. | **tidak disarankan** karena tesis berbahasa Indonesia |
| Kutipan langsung | dalam tanda petik **dan dicetak miring** |
| Referensi | minimal **10 jurnal internasional** |
| Website | **tidak dianjurkan** sebagai sumber |
| Daftar pustaka | urut abjad; contoh: `Demir, K.A., Gözde, D., Bülent, S., 2019., Industry 5.0 and Human-Robot, Co-working, Procedia Computer Science vol. 158, 688–695.` (tahun diikuti "., ") |

## 4. Abstrak (MSI, bagian tesis, hlm. 14)

Bahasa Indonesia, satu spasi, **150–200 kata**, berisi urgensi, rumusan masalah,
tujuan, metode, hasil (teori/model/metode), dampak. *Abstract* = versi Inggris.
Contoh abstrak tidak dibagi paragraf (Lampiran 13).

## 5. Pedoman diam

Cetak satu muka/bolak-balik; kedalaman subbab; ambang kemiripan; batas halaman.

## 6. Blok setelan

```
Sitasi        : (Demir, dkk, 2019); ≥ 10 jurnal internasional
Abstrak       : 150–200 kata
Sampul tesis  : buffalo Hijau Toscha; logo hitam-putih 5,5 × 4,7 cm
```
